LuckyDrawBox 配置说明

双击打开程序主界面，右上角有一个 “关于” 按钮，点击后会显示两个重要路径：

  • 配置目录（configuration 文件夹）的全路径
  • 中奖结果保存路径（output 文件夹）的全路径

1. configuration 文件夹

文件夹里面有两个重要配置文件：

  • participants.csv —— 抽奖人员名单
  • settings.json —— 奖项设置 + 动画主题

建议：修改前先备份一下这两个文件。文件必须是 UTF-8 格式！

1.1 participants.csv（抽奖人员名单,点击主界面"刷新配置"有打开这个文件的直达链接）

格式要求：每行必须有 4 列，用英文逗号 , 分隔
顺序严格为：ID, 姓名, 职务, 部门

修改方法：

  1. 用 Excel 打开 participants.csv
  2. 删除或覆盖示例数据，填入你自己的抽奖人员名单（保持 4 列格式）
  3. 保存为 CSV (逗号分隔) 格式，覆盖原文件
  4. 返回程序主界面，点击右上角 “刷新配置” 按钮，名单立即生效

示例内容：

# ID,姓名,职务,部门
A001,张伟,高级工程师,技术研发部
A002,李娜,产品经理,产品中心
A003,王磊,测试工程师,质量保障部
A004,赵六,,行政部
注意：职务可以为空（像赵六这样），但逗号分隔符必须保留。

1.2 settings.json（奖项设置 + 动画主题，点击主界面"刷新配置"可在软件中直接设置）

主要通过编辑这个文件来设置抽奖的奖项和每个奖项的获奖人数，同时可以切换抽奖过程中的动画主题（scheme）。

奖项及获奖人数设置

{
  "grand-prize": 0,        // 特等奖人数
  "1st-prize": 1,          // 一等奖人数
  "2nd-prize": 2,          // 二等奖人数
  "3rd-prize": 3,          // 三等奖人数
  "4th-prize": 0,          // 四等奖人数
  "5th-prize": 0,          // 五等奖人数
  "6th-prize": 0,          // 六等奖人数
  "hotpot-prize": 0        // 火锅奖人数
}

抽奖顺序：火锅奖 → 6等奖 → 5等奖 → 4等奖 → 3等奖 → 2等奖 → 1等奖 → 特等奖

奖项设置规则：

  • 火锅奖 和 特等奖：设为 0 就没有该奖项。
  • 6等奖 到 1等奖：一旦某个低等奖项人数不是 0，那么比它高的奖项直到 1等奖不能出现 0（不允许中间断档）。

修改完成后保存文件，然后点击主界面右上角 “刷新配置” 按钮，设置才会立即生效。

动画主题（scheme）

"scheme": "classic-red"

默认是 classic-red
可选值：classic-red、neon-purple、snow-season、flyin-red
修改后点击 “刷新配置” 按钮立即生效。

隐藏设置（secret setting）

"grand-prize-pred": "ID"
  "1st-prize-pred": "ID"

默认是 空
可选值：填写ID内定1等奖(如果有)和特等奖(如果有)获奖人1名(秘密功能，需手动编辑配置文件)
修改后点击 “刷新配置” 按钮立即生效。

2. output 文件夹（中奖结果）

点击右上角 “关于” 按钮，可查看 output 文件夹的全路径。

抽奖结束后，程序会自动在该文件夹生成中奖结果文件，文件名格式为：

result_YYYYMMDDHHMMSS.csv

实际示例：result_20260324154851.csv

该 CSV 文件记录了本次抽奖的所有中奖信息（奖项、ID、姓名、职务、部门等），方便后续查看和存档。
